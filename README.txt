# Abdellah Htet — Portfolio

## Files
- `index.html` — portfolio structure
- `style.css` — responsive dark design
- `script.js` — project modal, show-more, mobile navigation and contact form
- `assets/` — project cover illustrations and your portrait

## Before publishing
1. Put your own CV PDF in this folder and name it exactly `Abdellah-Htet-CV.pdf`.
2. Open `script.js` and replace `PASTE_YOUR_WEB3FORMS_ACCESS_KEY_HERE` with the Access Key from https://web3forms.com/.
3. Add GitHub repository URLs for the projects where the link is currently not available.
4. Open `index.html` in a browser or use VS Code Live Server.

## Contact form
The form is wired to Web3Forms. It will not send messages until you add your own Access Key in `script.js`.

## Notes
- The portrait in `assets/abdellah-photo.png` is the photo supplied for this portfolio.
- Project covers are custom SVG illustrations, not screenshots of the live applications.
- The CV PDF is intentionally not included; add your own file.

Skills section update: technology logos are displayed using Devicon CDN images; an internet connection is required for those logos to load.
